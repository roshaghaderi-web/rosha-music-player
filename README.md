# Rosha Music Player

A modern music player built with Next.js.

## Features

- Music playback and controls
- Play, pause, next and previous
- Search songs and artists
- Like and save favorite songs
- Repeat playback
- Volume control
- Responsive user interface

## Technologies

- Next.js
- React
- JavaScript
- Tailwind CSS
